# 2.1 Create New React Project using Vite Template

## Overview
Create a new React project using Vite template as the foundation for the Personal Expense Tracker application, setting up modern build tooling and development environment.

## Prerequisites
- Node.js 18.0.0+ installed and verified
- npm updated to latest version
- Command line access
- Internet connection for package downloads

## Steps

### 1. Create Vite React Project
```bash
# Create new project with Vite React template
npm create vite@latest money-lover-app -- --template react

# Alternative: Interactive mode
npm create vite@latest
# Then select:
# - Project name: money-lover-app
# - Framework: React
# - Variant: JavaScript
```

### 2. Navigate to Project Directory
```bash
cd money-lover-app
```

### 3. Install Dependencies
```bash
# Install all dependencies from package.json
npm install

# This will install:
# - React 18.x
# - React DOM 18.x
# - Vite 5.x
# - Development dependencies
```

### 4. Verify Project Structure
```
money-lover-app/
├── public/
│   └── vite.svg
├── src/
│   ├── assets/
│   │   └── react.svg
│   ├── App.css
│   ├── App.jsx
│   ├── index.css
│   └── main.jsx
├── .gitignore
├── index.html
├── package.json
├── README.md
└── vite.config.js
```

### 5. Test Development Server
```bash
# Start development server
npm run dev

# Expected output:
# VITE v5.x.x ready in ~500ms
# Local: http://localhost:5173/
# Network: use --host to expose
```

### 6. Verify in Browser
- Open http://localhost:5173/
- Should see Vite + React welcome page
- Verify React logo is spinning
- Check browser dev tools for no errors

### 7. Test Hot Reload
```bash
# Edit src/App.jsx
# Change "Vite + React" to "Money Lover App"
# Save file and verify browser updates automatically
```

### 8. Test Build Process
```bash
# Create production build
npm run build

# Expected output:
# dist/ folder created with optimized files
# Build completes without errors
```

### 9. Test Preview Mode
```bash
# Preview production build
npm run preview

# Expected output:
# Local: http://localhost:4173/
# Production build serves correctly
```

## Vite Configuration

### Default vite.config.js
```javascript
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

// https://vitejs.dev/config/
export default defineConfig({
  plugins: [react()],
})
```

### Optimization for Our Project
```javascript
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
  server: {
    port: 5173,
    open: true, // Auto-open browser
  },
  build: {
    outDir: 'dist',
    sourcemap: true, // For debugging
  },
  resolve: {
    alias: {
      '@': '/src', // Absolute imports
    },
  },
})
```

## Initial File Modifications

### Update src/App.jsx
```jsx
import { useState } from 'react'
import './App.css'

function App() {
  const [count, setCount] = useState(0)

  return (
    <div className="App">
      <h1>Money Lover - Personal Expense Tracker</h1>
      <p>Foundation setup complete!</p>
      <div className="card">
        <button onClick={() => setCount((count) => count + 1)}>
          count is {count}
        </button>
        <p>
          Edit <code>src/App.jsx</code> and save to test HMR
        </p>
      </div>
    </div>
  )
}

export default App
```

## Troubleshooting

### Common Issues

#### Permission Errors
```bash
# Clear npm cache
npm cache clean --force

# Use different registry
npm install --registry https://registry.npmjs.org/
```

#### Port Already in Use
```bash
# Find process using port 5173
npx kill-port 5173

# Or use different port
npm run dev -- --port 3000
```

#### Module Resolution Errors
```bash
# Delete node_modules and reinstall
rm -rf node_modules package-lock.json
npm install
```

#### Vite Issues
```bash
# Clear Vite cache
npx vite --force

# Or delete .vite cache
rm -rf node_modules/.vite
```
