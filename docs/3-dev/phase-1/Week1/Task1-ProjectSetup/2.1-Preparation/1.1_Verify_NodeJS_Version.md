# 1.1 Verify Node.js Version (18.0.0 or higher)

## Overview
Verify that Node.js version 18.0.0 or higher is installed on the development machine to ensure compatibility with React 18 and Vite 5.x.

## Prerequisites
- Access to command line/terminal
- Administrative privileges (if Node.js installation/update is needed)

## Steps

### 1. Check Current Node.js Version
```bash
node --version
```

Expected output format: `v18.0.0` or higher

### 2. Check npm Version
```bash
npm --version
```

Expected output: Latest stable npm version compatible with Node.js

### 3. Verify Compatibility
- **Minimum Required:** Node.js v18.0.0
- **Recommended:** Node.js LTS (Long Term Support) version
- **Current LTS as of 2024:** Node.js v20.x.x

### 4. Installation/Update (if needed)

#### Option A: Direct Download
1. Visit [nodejs.org](https://nodejs.org/)
2. Download LTS version
3. Install following platform-specific instructions

#### Option B: Using Node Version Manager (nvm)
```bash
# Install nvm (Unix/macOS)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash

# Install latest LTS
nvm install --lts
nvm use --lts

# Windows users can use nvm-windows
```

### 5. Verification
```bash
# Verify installation
node --version
npm --version

# Test basic functionality
node -e "console.log('Node.js is working!')"
```

## Expected Results
- Node.js version v18.0.0 or higher
- npm version 8.x.x or higher
- Successful execution of basic Node.js commands

## Troubleshooting

### Common Issues
1. **Permission errors**: Use administrator/sudo privileges
2. **Path issues**: Ensure Node.js is in system PATH
3. **Version conflicts**: Use nvm to manage multiple versions

### Verification Commands
```bash
# Check installation path
which node
which npm

# Check npm configuration
npm config list

# Verify React/Vite compatibility
npm info react@latest
npm info vite@latest
```
