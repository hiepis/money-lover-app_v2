# 1.2 Ensure npm is Available and Updated to Latest Version

## Overview
Verify that npm (Node Package Manager) is available and updated to the latest version to ensure compatibility with modern package management features and optimal development workflow.

## Prerequisites
- Node.js installed (completed in step 1.1)
- Command line access
- Internet connection for updates

## Steps

### 1. Check Current npm Version
```bash
npm --version
```

Expected output: Version number (e.g., `9.8.1`)

### 2. Check if Update is Available
```bash
npm outdated -g npm
```

This will show if npm itself needs updating.

### 3. Update npm to Latest Version
```bash
# Global npm update
npm install -g npm@latest

# Alternative: Update to specific version
npm install -g npm@9.8.1
```

### 4. Verify Update
```bash
# Check version again
npm --version

# Check npm installation location
npm config get prefix
```

### 5. Configure npm Settings

#### Basic Configuration
```bash
# Set npm registry (if needed)
npm config set registry https://registry.npmjs.org/

# Configure npm cache location
npm config set cache ~/.npm

# Set npm audit level
npm config set audit-level moderate
```

#### Optional: Performance Optimizations
```bash
# Enable strict SSL (recommended)
npm config set strict-ssl true

# Set progress indicator
npm config set progress true

# Configure parallel installation
npm config set package-lock true
```

### 6. Test npm Functionality

#### Basic Commands Test
```bash
# Test npm help
npm help

# Test npm search (requires internet)
npm search lodash

# Test npm info
npm info react
```

#### Test Package Installation (in a temp directory)
```bash
# Create test directory
mkdir npm-test && cd npm-test

# Initialize package.json
npm init -y

# Test install
npm install lodash

# Test uninstall
npm uninstall lodash

# Cleanup
cd .. && rm -rf npm-test
```

## Verification

### Version Requirements
- **Minimum npm version:** 8.x.x (comes with Node.js 18+)
- **Recommended:** Latest stable version (9.x.x+)
- **Compatibility:** Should work with React 18 and Vite 5.x

### Configuration Check
```bash
# View all npm configuration
npm config list

# View global packages
npm list -g --depth=0

# Check npm health
npm doctor
```

## Troubleshooting

### Common Issues

#### Permission Errors (Unix/macOS)
```bash
# Fix npm permissions
sudo chown -R $(whoami) ~/.npm
sudo chown -R $(whoami) /usr/local/lib/node_modules
```

#### Cache Issues
```bash
# Clear npm cache
npm cache clean --force

# Verify cache
npm cache verify
```

#### Registry Issues
```bash
# Reset registry to default
npm config delete registry

# Test connectivity
npm ping
```

### Windows-Specific Issues
- Run Command Prompt as Administrator for global installations
- Consider using Windows Subsystem for Linux (WSL) for better compatibility

## Configuration Best Practices

### Recommended Settings
```bash
# Security settings
npm config set audit-level moderate
npm config set fund false
npm config set strict-ssl true

# Performance settings
npm config set progress true
npm config set save-exact true
```

### Team Consistency
Create `.npmrc` file in project root:
```ini
save-exact=true
audit-level=moderate
fund=false
```
