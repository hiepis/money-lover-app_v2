## API Documentation

### Core Storage API Reference

#### `storage` Object

The core storage utility provides safe localStorage operations with error handling.

**Methods:**

##### `storage.get(key, defaultValue)`
Safely retrieve and parse data from localStorage.

**Parameters:**
- `key` (string) - Storage key
- `defaultValue` (any) - Value to return if key doesn't exist (default: null)

**Returns:** Parsed data or default value

**Example:**
```javascript
// Get with default value
const expenses = storage.get('expenses', []);

// Get user settings
const settings = storage.get('app_settings', {
  currency: 'USD',
  theme: 'light'
});
```

##### `storage.set(key, value)`
Safely stringify and store data in localStorage.

**Parameters:**
- `key` (string) - Storage key
- `value` (any) - Data to store

**Returns:** boolean - Success status

**Throws:** `StorageError` - If quota exceeded or storage unavailable

**Example:**
```javascript
// Store expense data
const success = storage.set('expenses', expenseArray);
if (!success) {
  console.error('Failed to save expenses');
}

// Store with error handling
try {
  storage.set('large_data', bigObject);
} catch (error) {
  if (error instanceof StorageError) {
    handleStorageError(error);
  }
}
```

##### `storage.remove(key)`
Remove item from localStorage.

**Parameters:**
- `key` (string) - Storage key

**Returns:** boolean - Success status

**Example:**
```javascript
// Remove specific item
storage.remove('temporary_data');

// Check result
if (storage.remove('old_cache')) {
  console.log('Cache cleared');
}
```

##### `storage.clear(appKeys)`
Clear all app data from localStorage.

**Parameters:**
- `appKeys` (string[]) - Array of keys to clear (optional)

**Returns:** boolean - Success status

**Example:**
```javascript
// Clear default app keys
storage.clear();

// Clear specific keys
storage.clear(['expenses', 'categories', 'cache']);
```

##### `storage.getSize()`
Get current storage usage information.

**Returns:** Object with usage statistics
```javascript
{
  used: number,        // Bytes used
  total: number,       // Total quota
  available: number,   // Available space
  usagePercent: number // Usage percentage
}
```

**Example:**
```javascript
const usage = storage.getSize();
console.log(`Storage: ${usage.usagePercent}% used`);

if (usage.usagePercent > 80) {
  showStorageWarning();
}
```

### Expense Storage API

#### Core Functions

##### `getAllExpenses()`
Retrieve all expenses sorted by date (newest first).

**Returns:** Array of expense objects

**Example:**
```javascript
const expenses = getAllExpenses();
console.log(`Total expenses: ${expenses.length}`);

// Display recent expenses
expenses.slice(0, 10).forEach(expense => {
  console.log(`${expense.date}: $${expense.amount}`);
});
```

##### `addExpense(expenseData)`
Add a new expense with validation.

**Parameters:**
- `expenseData` (Object) - Expense data
  ```javascript
  {
    amount: number,        // Required, > 0
    categoryId: string,    // Required
    description?: string,  // Optional, max 100 chars
    date: string          // Required, YYYY-MM-DD format
  }
  ```

**Returns:** Created expense object with generated ID and timestamps

**Throws:** Error if validation fails or storage error occurs

**Example:**
```javascript
// Add simple expense
const expense = addExpense({
  amount: 12.50,
  categoryId: 'food-dining',
  description: 'Coffee and pastry',
  date: '2024-01-15'
});

console.log(`Created expense with ID: ${expense.id}`);

// Handle validation errors
try {
  addExpense({
    amount: -10,  // Invalid negative amount
    categoryId: 'food'
  });
} catch (error) {
  console.error('Validation error:', error.message);
}
```

##### `updateExpense(id, updateData)`
Update an existing expense.

**Parameters:**
- `id` (string) - Expense ID
- `updateData` (Object) - Data to update (partial expense object)

**Returns:** Updated expense object

**Throws:** Error if expense not found or validation fails

**Example:**
```javascript
// Update expense amount
const updated = updateExpense('exp_123', {
  amount: 15.75,
  description: 'Updated lunch cost'
});

// Update category
updateExpense('exp_123', {
  categoryId: 'entertainment'
});
```

##### `deleteExpense(id)`
Delete an expense by ID.

**Parameters:**
- `id` (string) - Expense ID

**Returns:** boolean - Success status

**Throws:** Error if expense not found

**Example:**
```javascript
// Delete expense
try {
  const deleted = deleteExpense('exp_123');
  if (deleted) {
    console.log('Expense deleted successfully');
  }
} catch (error) {
  console.error('Failed to delete:', error.message);
}
```

#### Query Functions

##### `getExpensesByDate(date)`
Get expenses for a specific date.

**Parameters:**
- `date` (string) - Date in YYYY-MM-DD format

**Returns:** Array of expenses for the date

**Example:**
```javascript
// Get today's expenses
const today = new Date().toISOString().split('T')[0];
const todayExpenses = getExpensesByDate(today);

// Calculate daily spending
const total = todayExpenses.reduce((sum, exp) => sum + exp.amount, 0);
console.log(`Today's spending: $${total.toFixed(2)}`);
```

##### `getExpensesByMonth(year, month)`
Get expenses for a specific month.

**Parameters:**
- `year` (number) - Year (e.g., 2024)
- `month` (number) - Month (1-12)

**Returns:** Array of expenses for the month

**Example:**
```javascript
// Get current month expenses
const now = new Date();
const monthExpenses = getExpensesByMonth(
  now.getFullYear(),
  now.getMonth() + 1
);

// Group by category
const byCategory = monthExpenses.reduce((acc, exp) => {
  acc[exp.categoryId] = (acc[exp.categoryId] || 0) + exp.amount;
  return acc;
}, {});
```

##### `getDailyTotal(date)`
Calculate total expenses for a date.

**Parameters:**
- `date` (string) - Date in YYYY-MM-DD format

**Returns:** number - Total amount for the date

**Example:**
```javascript
// Daily spending tracker
const last7Days = Array.from({length: 7}, (_, i) => {
  const date = new Date();
  date.setDate(date.getDate() - i);
  const dateStr = date.toISOString().split('T')[0];
  
  return {
    date: dateStr,
    total: getDailyTotal(dateStr)
  };
});

console.log('Weekly spending trend:', last7Days);
```

### Category Storage API

#### Core Functions

##### `getCategories()`
Get all categories sorted by default status and name.

**Returns:** Array of category objects

**Example:**
```javascript
const categories = getCategories();

// Separate default and custom categories
const defaultCats = categories.filter(c => c.isDefault);
const customCats = categories.filter(c => !c.isDefault);

console.log(`${defaultCats.length} default, ${customCats.length} custom`);
```

##### `addCategory(categoryData)`
Add a new custom category.

**Parameters:**
- `categoryData` (Object) - Category data
  ```javascript
  {
    name: string,      // Required, max 30 chars
    color: string,     // Required, hex color
    icon: string       // Required, icon identifier
  }
  ```

**Returns:** Created category object

**Throws:** Error if validation fails or duplicate name

**Example:**
```javascript
// Add custom category
const category = addCategory({
  name: 'Pet Care',
  color: '#8b5cf6',
  icon: 'heart'
});

// Handle duplicate names
try {
  addCategory({
    name: 'Food & Dining',  // Duplicate of default category
    color: '#ef4444',
    icon: 'utensils'
  });
} catch (error) {
  console.error('Category exists:', error.message);
}
```

### Usage Patterns

#### React Component Integration

```javascript
// ExpenseManager.jsx
import { useState, useEffect } from 'react';
import { getAllExpenses, addExpense, getDailyTotal } from '../utils/expenseStorage';
import { getCategories } from '../utils/categoryStorage';

function ExpenseManager() {
  const [expenses, setExpenses] = useState([]);
  const [categories, setCategories] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    async function loadData() {
      try {
        const [expenseData, categoryData] = await Promise.all([
          getAllExpenses(),
          getCategories()
        ]);
        
        setExpenses(expenseData);
        setCategories(categoryData);
      } catch (error) {
        console.error('Failed to load data:', error);
      } finally {
        setLoading(false);
      }
    }

    loadData();
  }, []);

  const handleAddExpense = async (expenseData) => {
    try {
      const newExpense = await addExpense(expenseData);
      setExpenses(prev => [newExpense, ...prev]);
    } catch (error) {
      console.error('Failed to add expense:', error);
      // Show user-friendly error message
    }
  };

  if (loading) return <div>Loading...</div>;

  return (
    <div>
      <ExpenseForm onSubmit={handleAddExpense} categories={categories} />
      <ExpenseList expenses={expenses} />
    </div>
  );
}
```

#### Error Handling Pattern

```javascript
// storageService.js
import { storage, StorageError } from '../utils/storage';

export class StorageService {
  static async withErrorHandling(operation, fallback = null) {
    try {
      return await operation();
    } catch (error) {
      if (error instanceof StorageError) {
        // Handle storage-specific errors
        if (error.operation === 'set' && error.message.includes('quota')) {
          this.handleQuotaExceeded();
        } else {
          this.handleStorageUnavailable();
        }
      }
      
      console.error('Storage operation failed:', error);
      return fallback;
    }
  }

  static handleQuotaExceeded() {
    // Show storage full warning
    // Offer to clear old data
    console.warn('Storage quota exceeded');
  }

  static handleStorageUnavailable() {
    // Show offline mode indicator
    // Switch to memory-only storage
    console.warn('Local storage unavailable');
  }
}

// Usage
const expenses = await StorageService.withErrorHandling(
  () => getAllExpenses(),
  [] // Fallback to empty array
);
```

### Performance Guidelines

#### Batch Operations
```javascript
// Bad: Multiple individual operations
expenses.forEach(expense => {
  updateExpense(expense.id, { processed: true });
});

// Good: Batch update
const updatedExpenses = expenses.map(expense => ({
  ...expense,
  processed: true
}));
storage.set('expenses', updatedExpenses);
```

#### Memory Management
```javascript
// Monitor storage usage
function checkStorageHealth() {
  const usage = storage.getSize();
  
  if (usage.usagePercent > 80) {
    console.warn('Storage usage high:', usage.usagePercent + '%');
    
    // Clean up old data
    const cutoffDate = new Date();
    cutoffDate.setMonth(cutoffDate.getMonth() - 12);
    
    const expenses = getAllExpenses();
    const recentExpenses = expenses.filter(exp => 
      new Date(exp.date) > cutoffDate
    );
    
    storage.set('expenses', recentExpenses);
  }
}
```

### Data Migration Examples

```javascript
// Migration handler
import { dataMigration } from '../utils/validation';

async function handleAppUpgrade() {
  const currentVersion = storage.get('data_version', null);
  const targetVersion = '2.0.0';
  
  if (currentVersion !== targetVersion) {
    console.log(`Migrating data: ${currentVersion} -> ${targetVersion}`);
    
    const expenses = storage.get('expenses', []);
    const categories = storage.get('categories', []);
    
    // Perform migration
    const migratedData = dataMigration.migrateData(
      { expenses, categories },
      currentVersion,
      targetVersion
    );
    
    // Save migrated data
    storage.set('expenses', migratedData.expenses);
    storage.set('categories', migratedData.categories);
    storage.set('data_version', targetVersion);
    
    console.log('Data migration completed');
  }
}
```
