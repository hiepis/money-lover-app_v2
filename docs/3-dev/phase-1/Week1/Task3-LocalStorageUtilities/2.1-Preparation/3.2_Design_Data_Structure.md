## Schema Specifications

### Expense Object
```javascript
{
  id: "uuid-string",           // Unique identifier
  amount: 25.50,               // Decimal number, always positive
  categoryId: "food-dining",   // Reference to category
  description: "Lunch at cafe", // Optional description (max 100 chars)
  date: "2024-01-15",         // ISO date string (YYYY-MM-DD)
  createdAt: "2024-01-15T12:30:00Z", // ISO datetime
  updatedAt: "2024-01-15T12:30:00Z"  // ISO datetime
}
```

### Category Object
```javascript
{
  id: "food-dining",          // Unique identifier (kebab-case)
  name: "Food & Dining",      // Display name
  color: "#ef4444",           // Hex color code
  icon: "utensils",           // Icon identifier
  isDefault: true,            // Cannot be deleted if true
  createdAt: "2024-01-15T12:30:00Z" // ISO datetime
}
```

### Storage Keys
- `expenses` - Array of all expense objects
- `categories` - Array of all category objects  
- `app_settings` - Application configuration
- `data_version` - Schema version for migrations
